아두이노 보행자 버튼 신호등 프로젝트 가이드
버튼 클릭 시 신호등 LED 순차 제어, 부저 알림 및 멜로디 연주 회로/코드 종합 정리
1.
프로젝트 개요 및 동작 순서
본 프로젝트는 아두이노 UNO, 신호등 LED 모듈(G, Y, R), 보행자용 스위치 버튼, 피에조 부저를 사용하여 실제 도로의 보행자 신호등 시스템을 모사합니다. 내부 풀업 저항(INPUT_PULLUP)을 사용하여 외장 저항 없이 최소한의 와이어로 간결하게 회로를 구성하였습니다.
[동작 시퀀스]
•
대기 상태: 차량 통행을 위해 초록불(Green) ON 유지
•

1)

2)
빨간불(Red) ON (보행자 건너는 시간 5초 동안 유지)
3)
초록불(Green) ON (차량 통행 재개 10초 동안 유지 후 대기 상태 복귀)

// =========================================================
// 보행자 버튼 + 학교 종이 땡땡땡 멜로디 신호등 제어 코드
// 핀 배치: 스위치(2번), 피에조 부저(3번), 초록(8번), 노랑(9번), 빨강(10번)
// =========================================================
const int BUTTON_PIN = 2; // 보행자 스위치 (디지털 2번) const int BUZZER_PIN = 3; // 피에조 부저 (디지털 3번) const int GREEN_LED = 8; // 초록색 LED (디지털 8번) const int YELLOW_LED = 9; // 노란색 LED (디지털 9번) const int RED_LED = 10; // 빨간색 LED (디지털 10번)
const int NOTE_C4 = 262; const int NOTE_D4 = 294;
const int NOTE_E4 = 330; const int NOTE_G4 = 392; const int NOTE_A4 = 440;
int melody[] = {
NOTE_G4, NOTE_G4, NOTE_A4, NOTE_A4, NOTE_G4, NOTE_G4, NOTE_E4, NOTE_G4, NOTE_G4, NOTE_E4, NOTE_E4, NOTE_D4,
NOTE_G4, NOTE_G4, NOTE_A4, NOTE_A4, NOTE_G4, NOTE_G4, NOTE_E4, NOTE_G4, NOTE_E4, NOTE_D4, NOTE_E4, NOTE_C4
};
int noteDurations[] = {
300, 300, 300, 300, 300, 300, 600,
300, 300, 300, 300, 1000,
300, 300, 300, 300, 300, 300, 600,
300, 300, 300, 300, 1000
};
void setup() { pinMode(GREEN_LED, OUTPUT); pinMode(YELLOW_LED, OUTPUT); pinMode(RED_LED, OUTPUT); pinMode(BUZZER_PIN, OUTPUT);
pinMode(BUTTON_PIN, INPUT_PULLUP);
digitalWrite(GREEN_LED, HIGH); digitalWrite(YELLOW_LED, LOW); digitalWrite(RED_LED, LOW); noTone(BUZZER_PIN);
}
void loop() {
if (digitalRead(BUTTON_PIN) == LOW) { digitalWrite(GREEN_LED, LOW); digitalWrite(YELLOW_LED, HIGH);
for (int i = 0; i < 24; i++) { tone(BUZZER_PIN, melody[i]); delay(noteDurations[i]); noTone(BUZZER_PIN); delay(40);
}
digitalWrite(YELLOW_LED, LOW); digitalWrite(RED_LED, HIGH); delay(5000);
digitalWrite(RED_LED, LOW); digitalWrite(GREEN_LED, HIGH); delay(10000);
}
